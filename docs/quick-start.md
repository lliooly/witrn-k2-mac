# 快速开始

## 选对连接方式

| 目标 | 设备模式 | 操作 |
| --- | --- | --- |
| 查看曲线 / 记录 | 普通开机 | 用数据线连接 CC1/HID，进入「上位机」，选择接口并连接 |
| 固件 / 资源读写 | DFU | 断开设备电源，按住减号键，从 CC1/HID 口连接 Mac，再检测身份 |
| 编辑表盘 / E-Mark | 无需连接 | 打开相应页面，导入文件或新建工程 |
| 查看历史记录 | 无需连接 | 在上位机页面打开本地记录文件 |

## 第一次使用

1. 按 [README](../README.md#开始使用) 构建并打开应用。
2. 日常采集从「上位机」开始；记录需选择保存位置，结束后正常停止并关闭应用。
3. 修改表盘或开机图时先保存工程，再按页内教程操作。启用背景时先写背景再写布局；每次完成后按提示重新进入 DFU。
4. 固件升级按四步向导操作。官网下载和本地选择都不会自动开始刷写；核对设备与固件后再备份并升级。
5. 保留每次操作的备份。发生错误时停止并查看阶段提示，不连续盲目重试。

完整操作、快捷键和备份格式见[应用指南](macos-app.md)。

## 文件怎么选

| 文件 | 用途 |
| --- | --- |
| `.k2` | 设备固件，需从厂商渠道取得适用版本 |
| `.k2project` | 本应用表盘工程，保存布局及图片 |
| `.pic` | 官方表盘布局，不包含本应用全部工程数据 |
| BMP / PNG / JPEG | 图片输入；按设备尺寸转换，透明区域填黑 |
| `.k2emark` | 本应用 E-Mark 工程，包含集合和默认组 |
| `.wtemark` | 官方单条 E-Mark 配置 |
| CSV / SQLite | 记录导入导出，细节见[曲线工具](k2-monitor.md) |
| 备份 `manifest.json` | 资源恢复入口；不能用任意二进制替代 |

## 常见问题

**没有设备？** 检查是否为数据线、是否连接 CC1/HID、页面所需的普通 / DFU 模式是否匹配，并关闭可能占用接口的其他软件。多个接口时确认选择正确。

**自定义 E-Mark 是空的？** 自定义区与设备内置档位不同。尚未初始化时保留原始备份，可导入 `.wtemark` 或新增配置，确认参数后再写入。不要把空白区当成内置身份丢失。

**表盘和实机字形不同？** 画布使用示例读数，字体和基线是近似预览。背景 / 布局的完整实机效果仍需验证。

**下载的应用被 macOS 拦截？** 当前没有 Developer ID 签名或公证。先核对下载来源与发布摘要，按 macOS 给出的安全提示处理；也可自行从源码构建。项目不要求关闭系统整体安全保护。

**备份在哪里？** 应用数据目录为 `~/Library/Application Support/K2 Updater/`；包含 `Backups`、`Resource Backups`、`Logs` 等子目录。工程和记录也可能保存在你选择的位置。卸载或迁移前自行备份。

**写入失败怎么办？** 保存错误阶段、应用版本和脱敏描述，保留本地备份。擦写后设备可能处于不完整状态；恢复刷写本身尚未实机验证。不要在 Issue 上传固件、备份和原始日志。
